# count-pizza-eaten
Hey, wanna know how much pizza did you eat in all-you-can-eat pizza? check my app

## Run the development environment

Install the project dependencies, then start Expo with a tunnel:

```bash
npm install
npx expo start --tunnel
```

When the server is ready, scan the QR code in the terminal with Expo Go. Keep the
terminal running while you use the app. The tunnel lets your phone connect even
when it cannot reach your computer over the local network.
